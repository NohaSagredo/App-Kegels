# Estado del Proyecto: App-Kegels (Classic)

## 🎯 Objetivo General
* Aplicación ligera y eficiente para el entrenamiento del piso pélvico (Kegels), diseñada como una PWA (Progressive Web App) y ejecutable en escritorio mediante Eel (Python).

## 📌 Estado Actual
* Se ha separado exitosamente el proyecto avanzado (ahora llamado **BorBor**) a su propio repositorio.
* Este directorio ahora contiene exclusivamente la versión original/nativa de Kegels.

## 🗺️ Arquitectura
* **Frontend:** Vanilla HTML5, CSS y JavaScript.
* **Backend Escritorio:** Python con librería Eel.
* **Características:** Sistema de niveles, medidor de contracción, modo libre y persistencia local.

## 🛠️ Comandos de Desarrollo
* Ejecutar en escritorio: `python main.py` (Requiere `pip install eel`).
* Abrir versión web: Abrir `index.html` en el navegador.

## ✅ Tareas Completadas
* Separación de la versión React/Vite (BorBor) a un repositorio independiente.
* Limpieza de dependencias no relacionadas con la versión clásica.
